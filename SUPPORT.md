# Getting help with Amethystora

## Using it

- The Manual is on every machine: `Super+F1`, or **Manual** in the Amethystora menu. It describes the
  image it is installed on, so it is the first place to look.
- `ame` lists the commands, and **Help** in the Amethystora menu has *Something's wrong* and *What
  changed*.
- The [README](README.md) says what the images are, how to install and how to switch to Amethystora.

## A question

Ask in [Discussions](https://github.com/arsslensoft/amethystora/discussions). Amethystora is kept by one
maintainer in their own time, so answers can take a few days.

## A bug, or an idea

Search the [issues](https://github.com/arsslensoft/amethystora/issues), then open one with the
[bug report or feature request form](https://github.com/arsslensoft/amethystora/issues/new/choose).
Include the output of `rpm-ostree status`, which names the exact image. `ame report` gathers what
usually helps; read it before you paste it.

Please don't paste a password, a recovery key, a Vault backup or a private key anywhere, in an issue or
otherwise. Nobody who helps you will ever need one.

## A security problem

Don't open an issue. Follow the [security policy](SECURITY.md): a private report through a GitHub
security advisory.

## Something that isn't Amethystora's

A problem in a package Fedora or Universal Blue ships unchanged belongs to that project. An app
installed from Flathub belongs to its maker. When it is not clear which it is, ask here.
