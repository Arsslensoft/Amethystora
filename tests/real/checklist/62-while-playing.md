# While you play

Walk on a real machine on the beta image, as `50-beta.md` says. The lab checks the logic against a stand-in GameMode (suite 77); what it cannot
check is a real game asking the real daemon, and a real battery. Mark each line `→ PASS` or `→ FAIL: what was seen`.

- [ ] PLAY-01 Off is as before. How: `ame desktop while-playing off`, start a game with `gamemoderun` in Steam's launch options. Expect: banners show, no Playing in the pill, `ls $XDG_RUNTIME_DIR/amethystora/playing` finds nothing.
- [ ] PLAY-02 A real game starts it. How: `ame desktop while-playing on`, start a Steam game with `gamemoderun %command%` as its launch option (a Flatpak Steam reaches GameMode through its portal). Expect: within a second the pill says **Playing**, a normal banner (`notify-send test`) waits, an urgent one (`notify-send -u critical test`) shows.
- [ ] PLAY-03 The performance mode follows the plug. How: with PLAY-02 running on a laptop, read `busctl --system get-property org.freedesktop.UPower.PowerProfiles /org/freedesktop/UPower/PowerProfiles org.freedesktop.UPower.PowerProfiles ActiveProfile`, then unplug and plug the charger. Expect: `performance` while plugged in, back to what it was within seconds of unplugging, `performance` again on plugging in.
- [ ] PLAY-04 Changing the mode by hand ends the hold. How: while Playing and plugged in, pick Balanced in quick settings. Expect: it stays Balanced for this game; the card no longer says the performance mode is held.
- [ ] PLAY-05 The timed backup waits and then runs. How: while Playing, `TRIGGER_UNIT=x.timer /usr/libexec/amethystora-metered wait backup; echo $?`. Expect: exit 1 and the line "A game is playing". Close the game: `amethystora-backup.service` starts by itself (`systemctl --user status amethystora-backup.service`).
- [ ] PLAY-06 Let them run. How: while Playing, open the pill's card, press **Let them run**. Expect: the mark goes, banners show, the profile is back, the game goes on; a second game started does not hold it again until the first and second have both ended.
- [ ] PLAY-07 A game that crashes. How: kill the game's process hard (`kill -9`). Expect: gamemoded notices its client has gone, the count drops and everything is back; if gamemoded does not notice, the backup still runs again after six hours and nothing else stays held once the pill's **Let them run** is pressed.
- [ ] PLAY-08 A lock gives it back. How: while Playing, lock the screen with Super+L, wait a minute, unlock. Expect: while locked no performance hold (`busctl ... ActiveProfileHolds` is empty) and no mark; after the unlock the pill says Playing again.
- [ ] PLAY-09 The system update is never held. How: while Playing, `systemctl start uupd-manual.service`, and as root `TRIGGER_UNIT=x.timer /usr/libexec/amethystora-metered wait system; echo $?`. Expect: exit 0, the update runs.
- [ ] PLAY-10 It costs nothing while off or while no game plays. How: with the switch on and no game, `busctl --user monitor 2>&1 | head` for a minute while using the desktop; and with it off, `ame desktop while-playing off` then the same. Expect: no calls to GameMode or UPower from the shell with no game; none at all when off.
